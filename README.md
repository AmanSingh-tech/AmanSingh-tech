Full-stack engineer, mostly TypeScript and Python. These days I spend most of my time on AI agents that are useful *and* safe to leave running: they recommend instead of act, and they stop to ask a human when they're not sure.

I care about good defaults. A UI that feels obvious, an API that's hard to misuse, a test that actually runs. Small choices compound.

#### What I'm building

- **[Custo](https://github.com/AmanSingh-tech/Custo)**: policy-constrained triage for customer-support chats. It reads the conversation and suggests the next allowed step with a calibrated confidence score. It can't touch money or accounts.
- **[ReachAI](https://github.com/AmanSingh-tech/ReachAI)**: a local-first job-search outreach assistant that only sends what you approve.
- **[IronTest](https://github.com/AmanSingh-tech/IronTest)**: point it at a repo, describe what you're building, and get tests that actually run against your code.
- **[Agentic Agile Planner](https://github.com/AmanSingh-tech/agentic-agile-planner)**: agents that turn requirements into Jira epics and stories over the A2A protocol.
- **[NeuraAdapt AI](https://github.com/AmanSingh-tech/NeuraAdapt-AI)**: eye-tracking that spots where dyslexic students lose focus in a lecture and writes notes for those moments.
- **[CodeArena](https://github.com/AmanSingh-tech/CodeArena)**: a full-stack coding platform with its own code-execution service.
